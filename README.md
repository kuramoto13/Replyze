# 顧客対応の効率化アプリ

## 概要

**顧客対応の効率化アプリ**は、企業のカスタマーサポート担当者が、問い合わせ対応・分類・担当者への振り分けを効率的に行える業務支援ツールです。

顧客から届いた問い合わせ内容をAIが分析し、回答文を自動生成することができます。

## 対象ユーザー
  
- 日々、多くの問い合わせに対応している人
- 問い合わせ内容の確認や分類に時間がかかっている人
- 社内マニュアルの理解や回答作成が難しい人

## ユーザーの課題・困りごと
  
- 問い合わせ件数が多く、1件ずつ回答を作成するのに時間がかかる
- 同じような問い合わせに何度も対応する必要がある
- 問い合わせ内容を確認して、適切な担当者に振り分ける作業が負担になっている
- 社内マニュアルや資料から必要な情報を探すのに時間がかかる
- 担当者によって回答内容や対応品質にばらつきがある

## このアプリでできること

- AIが問い合わせ内容を分析し、回答案を自動生成
- 問い合わせ内容をカテゴリー別に自動分類
- 問い合わせの緊急度を判定し、適切な担当者を提案
- 社内マニュアルやFAQをもとに質問へ回答
- 問い合わせの対応状況や履歴を管理



## 使用技術

| 項目 | 技術 |
|---|---|
| プログラミング言語 | Python |
| フロントエンド | Streamlit |
| AIモデル | OpenAI API |
| AI検索 | LangChain・ChromaDB（導入予定） |
| データベース | SQLite（導入予定） |
| ソースコード管理 | GitHub |


## 使い方

1. アプリを開く
2. 問い合わせ内容を入力する
3. AIによる問い合わせ内容の分析を実行する
4. AIが生成した回答案を確認する
5. 必要に応じて回答を編集する
6. 担当者を確認して問い合わせを管理する


## 今後の開発予定

- AIによる問い合わせ回答案の自動生成
- 問い合わせ内容の自動分類
- 担当者の自動振り分け
- RAGを活用した社内マニュアル検索
- 問い合わせ履歴のデータベース管理
- ダッシュボードによる対応状況の可視化


## 画面

### 入力画面

顧客から届いた問い合わせ内容を入力し、AIによる分析・回答案の生成を行います。

#### 入力例①：配送に関する問い合わせ

| 項目 | 入力内容 |
|---|---|
| 問い合わせ内容 | 注文した商品がまだ届きません。配送状況を確認したいです。 |
| 問い合わせカテゴリー | 未指定（AIが自動分類） |
| 緊急度 | 未指定（AIが自動判定） |

#### 入力例②：返品に関する問い合わせ

| 項目 | 入力内容 |
|---|---|
| 問い合わせ内容 | 購入した商品を返品したいのですが、手続き方法を教えてください。 |
| 問い合わせカテゴリー | 未指定（AIが自動分類） |
| 緊急度 | 未指定（AIが自動判定） |

#### 入力例③：システムに関する問い合わせ

| 項目 | 入力内容 |
|---|---|
| 問い合わせ内容 | ログインしようとしてもエラーが表示されてログインできません。 |
| 問い合わせカテゴリー | 未指定（AIが自動分類） |
| 緊急度 | 未指定（AIが自動判定） |

### AIによる分析・回答画面

AIが問い合わせ内容を分析し、以下の情報を表示します。

- 問い合わせカテゴリー
- 緊急度
- 推奨担当部署
- AIによる回答案
- 回答の根拠となる社内マニュアル

### 問い合わせ管理画面

- 問い合わせ一覧
- 担当者・担当部署
- 対応状況
- 問い合わせ履歴
