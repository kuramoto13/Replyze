# 業務効率AI　Replyze

## 概要

**業務効率AI　Replyze**は、企業のカスタマーサポート担当者が、問い合わせ対応・分類・担当者への振り分けを効率的に行える業務支援ツールです。

顧客から届いた問い合わせ内容をAIが分析し、回答文を自動生成することができます。

## 開発背景

市役所（福祉部署）にて、団塊の世代が75歳（後期高齢者）を迎えるタイミングでの窓口・電話対応業務に従事していました。
対象者の急増に伴う問い合わせ件数のひっ迫に加え、複雑かつ細かな制度規定を確認しながら1件ずつ正確に回答・担当振り分けを行う業務に多くの時間がかかり、現場の対応スピードと品質の維持に強い課題を感じていました。

この実体験から「組織独自のマニュアルや規定を参照し、回答案の作成から緊急度判定・振り分けまでを一気通貫で支援する仕組みがあれば、現場の負担を劇的に減らせる」と考え、本アプリを開発しました。
転職後の民間企業でも幅広く活用できるよう、**ECサイトのカスタマーサポートや企業の問い合わせ窓口（民間企業バージョン）**を想定した設計・データ構成に落とし込んでいます。

## 対象ユーザー
  
- ECサイトのカスタマーサポート（CS）部署の問い合わせ窓口チーム
- 複雑な業務マニュアルや社内規定を読み解いて適切な回答を作るのに時間がかかり、担当部署への振り分け判断にも迷うことが多い方
- ショップ独自の細かな返品・キャンセル規定の把握が追いつかず、回答作成の判断に迷うことが多い方
- 配送状況の確認、返品・交換、注文変更など、日々大量に届く顧客からのメール・フォーム問い合わせに対応している担当者

## ユーザーの課題・困りごと

- キャンペーン時などに問い合わせが急増し、1件ずつ文面を作成していると返信が遅延してしまう
- 同じような問い合わせに何度も対応する必要がある
- 最優先で対応すべき案件と振り分けるべき案件の見極めが負担になっている
- 社内マニュアルや資料から必要な情報を探すのに時間がかかる

## このアプリでできること

- AIが問い合わせ内容を分析し、回答案を自動生成
- 問い合わせ内容をカテゴリー別に自動分類
- 問い合わせの緊急度を判定し、適切な担当者を提案
- トラブル発生時の対応マニュアルやFAQをもとに質問へ回答
- 問い合わせの対応状況や履歴を管理

| ソースコード管理 | GitHub |


## 使い方

1. アプリを開く
2. 問い合わせ内容を入力する
3. AIによる問い合わせ内容の分析を実行する
4. AIが生成した回答案を確認する
5. 必要に応じて回答を編集する
6. 担当者を確認して問い合わせを管理する


## 今後の開発予定

- AIによる問い合わせ回答案の自動生成
- 問い合わせ内容の自動分類
- 担当者の自動振り分け
- 社内メモ・メンション機能
- RAGを活用した社内マニュアル検索
- 問い合わせ履歴のデータベース管理
- 回答の「根拠（参照元）」の提示


## 画面

### 入力画面

顧客から届いた問い合わせ内容を入力し、AIによる分析・回答案の生成を行います。

#### 入力例①：配送に関する問い合わせ

| 項目 | 入力内容 |
|---|---|
| 問い合わせ内容 | 注文した商品がまだ届きません。配送状況を確認したいです。 |
| 問い合わせカテゴリー | 未指定（AIが自動分類） |
| 緊急度 | 未指定（AIが自動判定） |

#### 入力例②：返品に関する問い合わせ

| 項目 | 入力内容 |
|---|---|
| 問い合わせ内容 | 購入した商品を返品したいのですが、手続き方法を教えてください。 |
| 問い合わせカテゴリー | 未指定（AIが自動分類） |
| 緊急度 | 未指定（AIが自動判定） |

#### 入力例③：システムに関する問い合わせ

| 項目 | 入力内容 |
|---|---|
| 問い合わせ内容 | ログインしようとしてもエラーが表示されてログインできません。 |
| 問い合わせカテゴリー | 未指定（AIが自動分類） |
| 緊急度 | 未指定（AIが自動判定） |

### AIによる分析・回答画面

AIが問い合わせ内容を分析し、以下の情報を表示します。

- 問い合わせカテゴリー
- 緊急度
- 推奨担当部署
- AIによる回答案
- 回答の根拠となる社内マニュアル

### 問い合わせ管理画面

- 問い合わせ一覧
- 担当者・担当部署
- 対応状況
- 問い合わせ履歴
